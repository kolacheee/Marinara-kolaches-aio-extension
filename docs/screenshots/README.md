# Screenshots

Drop screenshots here and the README's placeholders will resolve. Each
placeholder in the root `README.md` looks like:

```markdown
> 🖼️ **Screenshot** · `docs/screenshots/<name>.png`
> _<what to capture>_
```

Replace that blockquote with the image once captured, e.g.:

```markdown
![The AIO console](docs/screenshots/console-overview.png)
```
